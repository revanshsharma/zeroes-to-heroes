
# Zeroes to Heroes Challenge

Welcome to **Zeroes to Heroes**, a hands-on learning challenge designed to help students move from learning concepts to building real-world tech projects.

This challenge focuses on:
- Learning by doing
- Real-world problem statements
- Practical skills over theory

## How It Works
- Tasks will be released weekly
- Participants submit work via GitHub
- Top contributors get recognition, rewards & goodies

## Domains Covered
- Web Development
- AI / ML
- Cloud & Automation
- Data & Analytics

## Submissions
All submissions must follow the format mentioned in `SUBMISSION.md`.
